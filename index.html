SKY-----

No game server, account, or matchmaking service. Create an invite, send the code to your friend in a message, and have them accept it. Your friend sends their reply code back. Gameplay then travels directly between browsers. Both laptops use the same controls: A/D move, W jump, S block, F strike, G skill, H ultimate. A public STUN service helps connect players behind routers; restrictive networks may still block direct P2P.
